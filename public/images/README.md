# Folder Penyimpanan Logo & Gambar Aplikasi

Anda dapat mengganti logo aplikasi dengan menempatkan file logo Anda di folder ini:

1. Simpan file logo Anda di folder ini dengan nama:
   - `logo.png` (disarankan format PNG transparan) atau
   - `logo.svg` atau
   - `logo.jpg`
2. Sistem pada halaman Login (`LoginPage.tsx`) dan Sidebar (`Sidebar.tsx`) akan otomatis mendeteksi dan menampilkan file `logo.png` Anda.
3. Ukuran resolusi yang disarankan: 256x256 pixel hingga 512x512 pixel.
