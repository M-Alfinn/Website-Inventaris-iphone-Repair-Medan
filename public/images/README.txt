========================================================================
FOLDER PENYIMPANAN LOGO & GAMBAR: /public/images/
========================================================================

Folder ini khusus digunakan untuk menyimpan file logo dan gambar aplikasi.

Cara Mengganti Logo Aplikasi dengan Logo Anda Sendiri:
1. Siapkan file logo toko/bisnis Anda (format disarankan: PNG transparan atau SVG).
2. Simpan file logo Anda di dalam folder ini dengan nama:
   - logo.png  (atau logo.svg / logo.jpg)
3. Halaman Login, Sidebar, dan Header akan langsung otomatis mendeteksi
   dan menampilkan logo Anda dari path /images/logo.png.
4. Ukuran ideal yang disarankan: 256x256 pixel hingga 512x512 pixel.
